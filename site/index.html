Built for big shoots

Landscape

45MP+ · 50MB+ / file

Even when every file is huge, the grid stays light. Open full size only for the frames you need to check.

Stage & live

3,000–10,000 per show

Tear through burst-heavy sets with the keyboard alone. Put two similar frames side by side to pick the better one.

Events & sports

Days of shooting at once

Same-day turnaround: export just the keepers to a separate folder and move on to delivery.

Made for culling, nothing else

No waiting

Thumbnails are generated in parallel in the background, so you can start the moment a folder opens — even with tens of thousands of files.

RAW as-is

Open files straight from the card — no developing or converting first.

NEF · ARW · CR2 · CR3 · RAF · ORF · RW2 · PEF · DNG · SRW · JPEG

The Windows version can’t display RAW files yet. JPEG works on both.

Stop anytime

Marks and position are saved automatically. Reopen the folder and you continue from the same frame.

First launch

Mac

  1. Open the downloaded .dmg
  2. Drag Glimpse into Applications
  3. Launch it from Applications. It’s notarized by Apple, so it opens normally

Windows

  1. Run the downloaded -setup.exe
  2. If you see “Windows protected your PC”, click More info
  3. Click Run anyway and follow the installer
